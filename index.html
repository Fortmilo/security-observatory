Overview hierarchy

OAuth-first by design

The Overview leads with OAuth grants requiring review. It does not describe a retained authorisation record as a live or usable credential, and it never tests a token by attempting to use it.

PrimaryOAuth grants retained by users and applications, including bounded inactive or frozen-user correlation where evidence exists.
Supporting orderExternal Client App inventory, Named and External Credentials, Sites and externally exposed endpoints, then Privileged Access Evidence.
Demoted native evidenceHealth Check, package and licence evidence remain available under SBS & Evidence instead of dominating the Overview.
Truthful gapsUnavailable evidence renders as “Not assessed — reason” with the unavailable evidence and a safe next action.

Current status

Built and validated privately; public release still curated

The private implementation contains the application and its validation history. This public repository is a sanitised documentation, validation and contribution surface, not a mirror of private source or Git history.

A generally available managed package or AppExchange listing is not claimed here. Installation remains sandbox-first while the public release path is completed.
